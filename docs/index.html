Raymond “Red” Reddington — Quote API

Best quotes from The Blacklist, browsable here and fetchable as JSON.

API endpoints (static JSON, no server required)

  • GET /api/quotes.json — all quotes
  • GET /api/quotes/<id>.json — single quote by id
  • GET /api/seasons.json — list of seasons with quote counts
  • GET /api/season/<season>.json — all quotes for a season
  • GET /api/season/<season>/episode/<episode>.json — quotes for a specific episode
  • GET /api/random.json — a random quote (fixed snapshot from the last build)
  • GET /api/meta.json — totals and build timestamp
